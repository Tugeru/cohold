# cohold

Shared funds. Shared control. A multi-approval treasury on Stellar Testnet, built with Next.js (App Router), TypeScript, and the Stellar/Soroban SDK.

## Getting started

See [`docs/cohold-runbook.md`](docs/cohold-runbook.md) for environment setup, demo mode, wallet mode with Freighter, and the wallet-free verification loop.

Product docs: [`docs/cohold-prd.md`](docs/cohold-prd.md), [`docs/cohold-srs.md`](docs/cohold-srs.md), [`docs/cohold-ui-ux-spec.md`](docs/cohold-ui-ux-spec.md).
